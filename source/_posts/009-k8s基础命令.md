# k8s基础命令

## 简述

kubectl 是用于控制 kubernetes集群的命令工具

语法格式为：`kubectl  [command]  [TYPE]  [NAME]  [flags]`

```tex
kubectl  [command]  [TYPE]  [NAME]  [flags]
command: 子命令，如create、get、describe、delete
type： 资源类型，可以表示单数，复数或缩写形式
name： 资源的名称，如果省略，则显示所有资源信息
flags： 指定可选标志，或附加的参数
```

## 一、操作命名空间（namespace）

### 查询

**查看namespace信息**

```shell
kubectl get ns
```

```shell
kubectl get namespace
```

以上为缩写和全写，所有用到namespace关键字皆可缩写

**查看namespace中pod**

```shell
kubectl -n my_ns get pods
```

### 创建

```shell
kubectl create ns your_namespace # 简写, 其中：your_namespace 为你自己的命名空间名称
kubectl create namespace your_namespace # 全写, 其中：your_namespace 为你自己的命名空间名称
```

### 删除

```sh
kubectl delete namespace your_namespace # 简写, 其中：your_namespace 为你自己的命名空间名称
kubectl delete namespace your_namespace # 全写, 其中：your_namespace 为你自己的命名空间名称
```

### 查看详情

```sh
kubectl describe ns your_namespace # your_namespace 为你自己的命名空间名称
```

## 二、操作pod

### 获取命名空间下容器(pod)列表

```sh
kubectl get pods -n your_namespace -o wide -w # your_namespace为你自己的命名空间名称
-n 指定命名空间 
-o wide 显示更加详细信息
-o name 只显示名字
-o yaml/json  以yaml/json语法格式显示资源对象
-w 持续监听
```

### 查看pod的详细信息

```sh
kubectl describe pod your_pod -n your_namespace # your_pod为自己的pod名称，your_namespace为你自己的命名空间名称
```

### 创建 && 运行

```sh
kubectl run [pod名称] --image=[镜像]:[镜像版本] --port=[对外端口] --namespace [namespace]
```

### 删除pod

```sh
kubectl delete pod [pod名称] -n [命名空间名称]
```

### 进入容器

```sh
kubectl exec your_pod -c 容器名称 -n your_namespace -it /bin/bash
# 在容器内执行命令
kubectl exec myweb -- ls
50x.html
index.html
```

### 根据资源对象文件运行命令

```sh
kubectl  create/apply/delete -f  资源文件名称.yaml
```

create 创建文件中定义的资源 
kubectl create .... --dry-run=client -o yaml(create主要用来生成资源对象的模板,一般都是用apply)
apply  创建(更新)文件中定义的资源 （主要用的就是这个）
delete 删除文件中定义的资源

### 排错

```
kubectl get pod <pod-name> -n <namespace> -o wide 查看pod运行在哪个节点上
kubectl get pod <podName> -c <containor> -n <namespace> 查看资源对象的状态信息
kubectl describe pod <podName> -n <namespace> 查询资源对象的属性信息Events下是事物日志,一般启动失败使用
Kubectl logs <podName> -c <containor> -n <namespace> -f  查看pod内容器日志 -f可选，表示持续
```
